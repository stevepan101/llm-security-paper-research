## 一句话总结

一个被 Anthropic 高置信度判断为中国国家支持的团体，用 Claude Code 搭建了一套自动化攻击框架，对约 30 个机构发起间谍攻击。AI 完成了 80–90% 的战术操作，人类只在少数关键节点做决策。

> 这是一篇“AI for Security”的**反面**材料：它记录的是 AI 能力被攻击者真实利用的情况，对理解威胁模型非常重要。

## 攻击生命周期

1. **选定目标与搭建框架**（人类）：选择目标，搭建以 Claude Code 为核心的攻击编排框架。
2. **侦察**（AI）：检查目标的系统和基础设施，识别价值最高的数据库，并向操作者汇报。
3. **利用**（AI）：发现并测试漏洞，自己编写 exploit，收集凭据，提取数据并按情报价值分类，识别高权限账户，植入后门，外传数据。
4. **整理文档**（AI）：生成被盗凭据和已分析系统的清单，为下一阶段做准备。

## 如何绕过模型的安全机制

- **任务拆分**：把攻击拆成许多看起来无害的小任务，模型始终看不到完整的恶意意图；
- **角色伪装**：告诉模型它在为一家正规网络安全公司做防御性测试。

## 工具与规模

- 通过 **MCP（Model Context Protocol）** 接入工具：网络搜索、数据获取、密码破解器、网络扫描器等。
- 高峰期每秒发出多个请求，总计数千次，这是人类团队无法达到的速度。
- 每次行动中人类只做约 **4–6 个关键决策**。

## AI 的局限

- 模型有时会**幻觉出凭据**，或者声称拿到了机密信息，实际上那是公开信息。这反而成了攻击者全自动化的障碍。

## 结果与响应

- 攻击约 30 个机构（大型科技公司、金融机构、化工企业、政府机构），**少数**攻击成功。
- Anthropic 用约 10 天调查清楚范围，封禁了账号，通知受影响方，与执法机构协作，并改进了检测分类器。

## 意义

1. **威胁模型的实证更新**：“AI agent 自主执行大部分攻击链”已经不是假设，而是有记录的事件。
2. 揭示了一种对齐层面的弱点：**任务拆分加角色伪装**可以让单轮安全检查失效，防御需要在会话或账户层面关联上下文。
3. MCP 等 agent 工具协议同时提升了攻击者的效率，**agent 生态的滥用检测**成为新的防御重点。

## 局限与疑问

- 报告由模型提供方单方面发布，归因细节和受害者信息有限，外部无法独立核实。
- 部分安全研究者质疑“80–90% 自动化”的口径和这次事件的“首次”性质。

## 对研究者的启示

- 多轮、跨会话的恶意意图检测（与 [17 Crescendo](../security-for-ai/17-crescendo-multi-turn-jailbreak.md) 的多轮越狱问题相关）。
- 如何评估 agent 在“任务被拆分”的情况下识别整体恶意目标的能力。
