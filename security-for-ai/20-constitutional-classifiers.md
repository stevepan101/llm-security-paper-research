# Constitutional Classifiers（及新一代 Constitutional Classifiers++）

| 项目 | 内容 |
|---|---|
| 机构 | Anthropic（Safeguards Research Team） |
| 时间 | 第一代 2025-02；新一代 2026-01-09 |
| 原文 | [arXiv:2501.18837](https://arxiv.org/abs/2501.18837)、[新一代介绍](https://www.anthropic.com/research/next-generation-constitutional-classifiers)、[Dark Reading 报道](https://www.darkreading.com/application-security/constitutional-classifiers-mitigate-genai-jailbreaks) |

## 一句话总结

用自然语言写一份“宪法”，规定哪些内容允许、哪些禁止（重点是 CBRN 等高危领域）；再让 LLM 依据宪法生成大量合成数据，用来训练输入和输出分类器。目标是防御**通用越狱**，也就是一个越狱提示就能解锁所有危险问题的情况。它经过了数千小时公开红队和漏洞赏金的检验。

## 背景与问题

模型级的安全训练会被越狱绕过（见 [12](12-shallow-safety-alignment-iclr25.md)、[16](16-many-shot-jailbreaking-neurips24.md)）。对于生物武器等高危信息，部署方需要额外的防线，而且这条防线要满足：(1) 很难被通用越狱绕过；(2) 误拒率足够低；(3) 计算开销可以接受。

## 方法（第一代）

1. **宪法**：用自然语言规则描述允许和禁止的内容类别；
2. **合成数据**：用 LLM 依据宪法生成大量有害和无害的样本，并做数据增强（翻译、改写、加入已知的越狱风格等）；
3. **输入分类器**：在提示到达模型之前进行拦截；
4. **输出分类器**：对生成内容做**流式**判断，发现有害内容可以在生成过程中中止；
5. 宪法可以快速更新，以应对新的攻击类型。

## 结果

### 第一代
| 指标 | 数值 |
|---|---|
| 自动化越狱测试的成功率 | 无防护 86% → 有防护 **4.4%**（拦截约 95%） |
| 人类红队 | 3000 多小时；**没有发现**能在大多数目标问题上得到与无防护模型同等详细信息的通用越狱 |
| 公开漏洞赏金 | 最终发现 **1 个**通用越狱 |
| 误拒增加 | 生产流量中拒绝率绝对值增加 0.38% |
| 计算开销 | 推理开销增加 23.7% |

### 新一代 Constitutional Classifiers++（2026-01）
- **架构**：
  - 一个轻量的**线性探针**读取模型内部激活，筛查所有流量；
  - 被标记的对话再交给更强的“探针加分类器”集成模型做最终判断；
  - 强分类器同时看输入和输出，而不是分别判断。
- **开销**：只增加约 **1%** 的计算成本（第一代是 23.7%）。
- **误拒**：在 Claude Sonnet 4.5 的一个月流量上，良性请求的拒绝率为 **0.05%**，比第一代降低 87%。
- **红队**：1700 多小时、19.8 万次尝试，发现 1 个高风险漏洞，没有发现通用越狱。

## 贡献与意义

1. **大规模实证检验**：很少有防御能经受数千小时公开红队和漏洞赏金的考验，这比实验室内的评估可信得多。
2. **工程可行性**：新一代把开销从 23.7% 降到约 1%，误拒降到 0.05%，已经可以在生产中全量部署（Claude Opus 4 起用于 ASL-3 防护）。
3. **基于激活的探针**：利用模型内部表示做检测，比只看文本更难被绕过，也更便宜。
4. 验证了 [16 Many-shot](16-many-shot-jailbreaking-neurips24.md) 提出的“输入侧分类”思路，并把它系统化了。

## 局限

- 它针对的是**通用越狱**和特定高危领域，不能防御所有有害内容，也不针对提示注入。
- 分类器本身也是模型，原则上可能被自适应攻击绕过（[14](14-attacker-moves-second-usenix26.md) 攻破了 PromptGuard、Model Armor 等分类器），漏洞赏金中也确实找到了一个通用越狱。
- 依赖访问模型内部激活，只适用于模型提供方自己部署。

## 对研究者的启示

- 宪法加合成数据的方法可以迁移到其他安全分类任务（例如网络安全滥用检测，Anthropic 在 [04](../ai-for-security/04-claude-opus-4-6-500-zero-days.md) 中提到的网络安全探针）。
- “低成本探针做初筛，高成本模型做复核”的级联架构，是安全部署中平衡成本和效果的通用模式。
