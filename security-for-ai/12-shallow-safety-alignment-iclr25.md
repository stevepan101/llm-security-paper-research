# Safety Alignment Should Be Made More Than Just a Few Tokens Deep

| 项目 | 内容 |
|---|---|
| 作者 | Xiangyu Qi, Ashwinee Panda, Kaifeng Lyu, Xiao Ma, Subhrajit Roy, Ahmad Beirami, Prateek Mittal, Peter Henderson（Princeton、Google DeepMind） |
| 会议 | ICLR 2025，**Outstanding Paper Award** |
| 原文 | [arXiv:2406.05946](https://arxiv.org/abs/2406.05946)、[ICLR 2025 获奖名单](https://media.iclr.cc/Conferences/ICLR2025/ICLR2025_Outstanding_Paper_Awards.pdf) |

## 一句话总结

当前的安全对齐基本只改变了模型回复**前几个 token** 的分布，作者称之为“浅层安全对齐”。这一个根因可以统一解释后缀攻击、预填充攻击、解码参数攻击和微调攻击为什么会成功。作者提出了两种把对齐“加深”的方法。

## 背景与问题

后缀攻击、预填充攻击、解码参数攻击和微调攻击都能让已对齐的大模型输出有害内容，但这些攻击一直被当作互不相关的问题分别研究。作者追问：它们是否有共同的根因？如果有，对齐本身的“深度”是否不够，又该怎样加深？

## 核心洞察：浅层对齐

- **证据**：对比对齐模型和基础模型在有害问题上每个位置 token 的 KL 散度，前几个位置远高于后面的位置（Llama-2 和 Gemma 都如此）。也就是说，对齐的“预算”几乎都花在了开头。
- **直观理解**：对齐模型学会了用“I cannot…”开头，但只要开头被绕过，后面的生成和基础模型差不多。
- **反向验证**：只要给**基础模型**强制加上拒绝前缀（例如 “I apologize, but I cannot”），它的有害率就会从 68.6% 降到 2.1%（Llama-2-7B）。这说明“对齐效果”很大程度上就是“前几个 token 的效果”。

## 统一解释四类攻击

| 攻击 | 为什么能成功 |
|---|---|
| 预填充攻击（prefilling） | 直接替模型写好有害的开头，跳过了被对齐的那几个 token。预填充的有害 token 越多，ASR 从接近 0 升到 50% 以上 |
| 对抗后缀（GCG） | 优化目标就是让模型以“Sure, here is…”开头，正好针对浅层对齐 |
| 解码参数攻击 | 调整 temperature、top-k、top-p 随机采样，有一定概率在开头采样出非拒绝的 token |
| 微调攻击 | 改变开头几个 token 的分布只需要很小的更新：用 100 个有害样本微调 Llama-2-7B-Chat，6 步梯度更新就让 ASR 从 1.5% 升到 87.9% |

## 方法

### 1. 数据增强：安全恢复样本
构造“先以有害内容开头，中途转为拒绝”的训练样本，教模型**即使已经开始输出有害内容也能回到安全轨道**，让对齐作用延伸到更深的位置。

### 2. 约束初始 token 的微调目标
提出一个带 token 级正则的微调目标，限制微调时对开头几个 token 分布的改变幅度，使安全对齐在下游微调中更持久。

## 关键结果

以下数字均来自原文第 3、4 节，ASR 为攻击成功率（%），除特别说明外为三次运行的均值。

### 数据增强（第 3 节，Llama-2-7B-Chat）

安全集为 256 条（指令、有害回复、拒绝）三元组，实用性数据取自 Alpaca，增强后的模型与原始 Llama-2-7B-Chat 比较：

| 攻击 | 评测集 | 原始模型 ASR | 增强后 ASR |
|---|---|---|---|
| 预填充 5 个 token | HEx-PHI | 42.1 | 2.8 |
| 预填充 40 个 token | HEx-PHI | 57.0 | 4.5 |
| GCG | AdvBench | 65.6 | 19.0 |
| 解码参数攻击 | MaliciousInstruct | 84.3 | 1.0 |

- 通用能力：AlpacaEval 对 text-davinci-003 的胜率从 51.8% 降到 49.5%，作者称仅略有下降。
- GCG 在 HEx-PHI 上从 36.5 降到 18.4，说明对抗后缀并未被完全防住。

### 约束微调目标（第 4 节）

对比标准 SFT 与约束 SFT（Llama-2-7B-Chat / Gemma-1.1-7B-IT）：

| 微调数据 | 指标 | Llama-2 标准 SFT | Llama-2 约束 SFT | Gemma 标准 SFT | Gemma 约束 SFT |
|---|---|---|---|---|---|
| 有害样本（Harmful Examples） | ASR | 88.9 | 4.6 | 81.6 | 1.9 |
| 身份转换（Identity Shifting） | ASR | 79.5 | 8.1 | 83.6 | 9.1 |
| 后门（有触发词） | ASR | 90.9 | 10.9 | 82.3 | 1.9 |
| Samsum | ASR / ROUGE-1 | 23.4 / 51.7 | 3.2 / 50.1 | 2.0 / 51.5 | 2.4 / 51.9 |
| GSM8k | ASR / 准确率 | 3.3 / 41.7 | 2.0 / 37.4 | 2.9 / 63.3 | 1.7 / 63.6 |

- 在良性下游任务上，约束 SFT 的实用性与标准 SFT 接近；差距最大的是 Llama-2 的 GSM8k（37.4 对 41.7）。
- 表中“标准 SFT”的有害样本 ASR（88.9）与上文“100 个有害样本、6 步更新”的 87.9% 设置不同，不要混用。

## 贡献与意义

1. **一个概念统一了一大类攻击**：这是它获得 Outstanding Paper 的主要原因。很多看似不同的越狱手法有同一个根因。
2. 指出评估对齐时不能只看“开头有没有拒绝”，需要考察更深位置的行为。
3. 对开源模型提供方很有现实意义：微调攻击是开源权重模型面临的主要威胁。

## 局限

- 数据增强只能覆盖训练中见过的有害模式，面对自适应攻击（见 [14](14-attacker-moves-second-usenix26.md)）的鲁棒性仍需检验。
- 约束微调目标需要模型提供方控制微调流程，对“攻击者自己微调开源权重”的情况无效。
- 实验主要在 7B 级模型上进行。

## 对研究者的启示

- “对齐深度”可以作为一个可度量的指标，用于比较不同对齐方法。
- 与表示工程、电路分析结合：浅层对齐在模型内部是怎么实现的？
