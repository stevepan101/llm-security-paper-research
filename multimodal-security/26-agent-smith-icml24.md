# Agent Smith: A Single Image Can Jailbreak One Million Multimodal LLM Agents Exponentially Fast

| 项目 | 内容 |
|---|---|
| 作者 | Xiangming Gu, Xiaosen Zheng, Tianyu Pang（共同一作）, Chao Du, Qian Liu, Ye Wang, Jing Jiang, Min Lin（Sea AI Lab、新加坡国立大学、新加坡管理大学） |
| 会议 | ICML 2024 |
| 原文 | [PMLR 论文页](https://proceedings.mlr.press/v235/gu24e.html)、[arXiv:2402.08567](https://arxiv.org/abs/2402.08567)、[代码](https://github.com/sail-sg/Agent-Smith) |

## 一句话总结

在多智能体系统中，只要把一张对抗图像放进**一个**智能体的相册，它就会在智能体之间的两两对话中像病毒一样传播。模拟实验中，一百万个 LLaVA-1.5 智能体在约 27–31 轮对话后几乎全部被越狱。作者称之为“传染式越狱”（infectious jailbreak）。

## 背景与问题

越狱研究通常针对单个模型、单次对话。但多模态 LLM 越来越多地以多智能体形式部署：智能体有记忆、会检索图片、彼此交流。如果越狱能在智能体之间自我复制，攻击者只需攻破一个入口，代价从 O(N) 降到 O(log N)。

## 方法

**多智能体环境**：
- 每个智能体由一个多模态 LLM（默认 LLaVA-1.5 7B）、一个基于 CLIP 的检索器、文本历史（默认长度 3）和图片相册（默认 10 张，先进先出）组成，并有各自的角色设定。
- 每一轮，智能体被随机配对为提问者和回答者。提问者从相册中检索一张图片并提问，回答者作答；这张图片会被**存入回答者的相册**。

**对抗图像需要同时满足三个“通用”条件**：
1. 在任何相册中都能被检索器选中（因此会被继续传播）；
2. 在任何对话历史下，让提问者提出有害问题；
3. 在任何对话历史下，让回答者给出有害回答。

作者从一个未被攻击的系统中采样 512 条对话记录作为优化数据，以一张良性的 ArtBench 图像为起点，用基于动量的迭代攻击优化三项损失之和。扰动有两种：像素攻击（ℓ∞ ≤ 8/255 或 16/255）和只修改细边框的边框攻击（宽度 6 或 8 像素）。

**传播理论**：把感染过程建模为类似传染病的动力学，传播率 β、发病率 α、恢复率 γ（被感染图片从相册中被挤出）。当 β > 2γ 时，携带病毒的比例收敛到 1 − 2γ/β；当 β ≤ 2γ 时收敛到 0。达到全面感染所需轮数为 O(log N)。

## 关键结果

- **百万规模**：一百万个智能体中，几乎全部在约 27–31 轮后被感染。为降低成本，实验在 1024 个智能体的相册中预置了这张图像（初始比例 1/1024），而不是只放进一个智能体。
- **对比基线**（256 个智能体）：视觉提示注入和文本提示注入都无法感染任何智能体；逐个越狱（每轮只攻破一个）32 轮后只覆盖约 1/8；传染式越狱呈指数增长。
- **主实验**（256 个智能体，表 1）：边框攻击（h = 8）在第 16 轮的累计感染率为 91.95%，平均约 16 轮达到 90%；像素攻击（8/255）为 89.30%。
- **失败条件**：扰动预算过小（边框宽度小于 6 或 ℓ∞ 小于 8/255）时可能增长缓慢或中途回落；相册容量缩小到 2 时恢复率上升，传播变慢（第 16 轮累计感染率降到 76.17%）。
- **推广**：对 InstructBLIP 7B、LLaVA 与 InstructBLIP 各半的异构系统，以及诱导输出有害函数调用（JSON）的场景同样有效。
- **理论推论**：β = 1、γ = 0 时，从一百万扩展到十亿个智能体只需多约 14 轮。

## 贡献与意义

1. **提出多智能体场景下的新威胁模型**：越狱可以自我复制，攻击成本随规模对数增长。
2. **给出可证明防御的条件**：任何防御只要能保证 β ≤ 2γ（降低传播或加快恢复），感染就会消退。这为防御设计提供了明确的目标，但作者也承认尚无满足该条件的实用防御。
3. 与 [15 AgentDojo](../security-for-ai/15-agentdojo-neurips24.md)、[19 CaMeL](../security-for-ai/19-camel-defeating-prompt-injections.md) 关注的单智能体注入互补，本文研究的是**智能体之间**的传播。

## 局限

- 环境是简化的随机两两对话，单向传播；真实的多智能体系统通信结构更复杂。
- 百万规模的结果是降低成本的模拟（预置 1024 个初始感染者），不是严格的“一张图感染一百万”。
- 只认精确匹配的有害字符串为成功，作者认为这可能低估了效果；同时攻击是白盒的，需要知道模型和检索器。
- 没有提出实用防御；作者提到的输入净化、对抗训练等候选防御都可能被自适应攻击绕过（参见 [14](../security-for-ai/14-attacker-moves-second-usenix26.md)）。

## 对研究者的启示

- 智能体的**记忆和共享存储**是新的攻击面：任何会被检索并转发的内容都可能成为传播载体。
- 设计多智能体系统时，可以把“恢复率”当作安全参数：限制记忆保留时间、对检索内容做隔离或去重，都是提高 γ 的手段。
- 评估多智能体安全时应关注系统级指标（感染比例随时间的变化），而不只是单次攻击成功率。
