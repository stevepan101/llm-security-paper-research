## 一句话总结

给视觉语言模型（Vision-Language Model, VLM）加上视觉输入，等于开了一个连续、可求梯度的攻击面：只需优化**一张**对抗图像，就能让已对齐的模型对大量**没参与优化**的有害指令言听计从。这是多模态越狱研究的奠基工作之一。

## 背景与问题

文本越狱需要在离散的 token 空间里搜索，难度高、成本大。而图像是连续的高维输入，计算机视觉领域十几年的对抗样本（adversarial example）研究表明，这类输入几乎无法做到鲁棒。作者想回答：把视觉接入已对齐的 LLM 后，安全对齐还能维持多少？

## 方法

- **威胁模型**：白盒（可以拿到模型权重和梯度）为主，另测黑盒迁移。目标是**通用**对抗图像：一张图对任意有害指令都起作用。
- **优化目标**：用一个只有 66 句贬损性语句的小语料（针对某一性别、某一种族和全人类，由未对齐的 LLaMA-1 生成后人工筛选），最大化模型在这张图像条件下生成这些语句的概率。作者把它类比为提示微调（prompt tuning）：图像像一个对抗性“软提示”，把模型切换进“越狱模式”。
- **优化细节**：PGD，5000 步。分为无约束（从随机噪声开始）和有约束（从一张熊猫图出发，ℓ∞ 扰动上限 ε = 16/255、32/255、64/255）两种。
- **被攻击模型**：MiniGPT-4（Vicuna 13B）、InstructBLIP（Vicuna 13B）、LLaVA（LLaMA-2-13B-Chat）。
- **使用方式**：推理时把对抗图像和任意有害文本指令一起输入。
- **文本对照组**：用 AutoPrompt 式的离散 token 搜索构造 32 个对抗 token（对应 MiniGPT-4 的 32 个图像 token），计算量约为图像攻击的 12 倍。

## 关键结果

**人工评估**（MiniGPT-4，40 条人工整理的有害指令，每条采样 10 次，表 1）：

| 设置 | 身份攻击 | 虚假信息 | 暴力 / 犯罪 | 人类灭绝类 |
|---|---|---|---|---|
| 良性图像（无攻击） | 26.2% | 48.9% | 50.1% | 20.0% |
| 对抗图像 ε = 16/255 | 61.5% | 58.9% | 80.0% | 50.0% |
| 对抗图像 ε = 32/255 | 70.0% | 74.4% | 87.3% | 73.3% |
| 对抗图像（无约束） | 78.5% | 91.1% | 84.0% | 63.3% |
| 对抗文本（无约束） | 58.5% | 68.9% | 24.0% | 26.7% |

注意：优化只用了贬损性语料，但对虚假信息、暴力等**完全不同类别**的指令也有效，说明图像带来的是通用越狱而不是记住了某些句子。

**RealToxicityPrompts 挑战子集**（Perspective API 判定任一毒性属性的比例，表 2）：MiniGPT-4 从无攻击的 34.8% 升到 67.2%（ε = 64/255）；对抗文本只有 54.8%。

**其他模型（白盒）**：InstructBLIP 从 34.2% 升到最高 61.3%，LLaVA（基于 LLaMA-2-Chat，当时对齐最充分的开源模型）从 9.2% 升到最高 52.3%。

**迁移**：在一个模型上优化的图像迁移到其他模型，毒性也一致上升，但幅度明显小于白盒。例如在 InstructBLIP 上优化的图像迁移到 LLaVA，毒性比例从 9.2% 升到 20.6%（白盒攻击 LLaVA 可达 52.3%）。

**防御**：用 DiffPure（加噪后用扩散模型去噪）净化输入，能把多数设置的毒性比例拉回接近基线（如无约束攻击从 66.0% 降到 31.0%–33.8%）。但作者指出它可能被自适应攻击绕过，而且对攻击者本地部署的开源模型毫无作用。

## 贡献与意义

1. **指出了多模态的根本性问题**：模态越多，攻击面越大；连续输入空间的对抗脆弱性会直接传递给 LLM 的安全对齐。
2. **证明了“通用越狱图像”的存在**：一张图、一次优化，对大量未见指令生效，与同期 GCG（Greedy Coordinate Gradient）的通用对抗后缀思路一致。
3. **图像攻击比文本攻击更强更省**：在更小的计算预算下，图像攻击达到更低的损失和更高的有害率。
4. 作者团队随后提出“浅层对齐”理论（[12](../security-for-ai/12-shallow-safety-alignment-iclr25.md)），可以视为对这类越狱为什么奏效的更深一层解释。

## 局限

- 主要是白盒攻击；对闭源商用模型的威胁要靠迁移，而后来的研究发现图像越狱的迁移非常困难（[28](28-failures-transferable-image-jailbreaks-iclr25.md)）。
- 只测了三个 13B 级别的模型，均已过时；作者自己称结果是“概念验证”。
- 有害性评估依赖人工标注和 Perspective API 等自动工具，作者承认这些评估不完整。

## 对研究者的启示

- 评估多模态模型的安全性必须包含**非文本通道的对抗输入**，不能只做文本红队。
- 开源 VLM 等于把梯度交给了攻击者；对开源权重模型，输入净化这类在线防御无效，需要在训练阶段提高鲁棒性。
- 和后续工作对比阅读：白盒几乎必胜（本文），迁移却很难（[28](28-failures-transferable-image-jailbreaks-iclr25.md)），而不需要梯度的排版类攻击（[25 FigStep](25-figstep-aaai25.md)）和随机增强（[27 BoN](27-best-of-n-jailbreaking-neurips25.md)）反而能打到闭源模型。
